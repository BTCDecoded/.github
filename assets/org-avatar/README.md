# BTCDecoded organization avatar

This folder holds the official v15 mark to upload as the BTCDecoded GitHub organization avatar, and a capture of the current avatar for comparison.

Merging this pull request does not change the live organization avatar. Step 3 below does.

## Proposed mark

`btcdecoded_org_avatar_512.png`

- Source: the official v15 kit (`03_FAVICONS/favicon_512.png`), used as is, no new art.
- sha256: `95be31cb91810c1a1b5d4666b5495bb11e24f6312b74152ac3eabc2a9490a87b`
- 512x512 PNG. Official v15 circle mark: a white ₿ on an orange disc, transparent background. GitHub asks for a square of at least 500px, so this file is the right size.

![Proposed BTCDecoded org avatar, official v15 circle mark](btcdecoded_org_avatar_512.png)

## Apply steps

An organization owner applies the avatar in the GitHub UI. Merging this pull request does not change the avatar. Step 3 does.

1. Open https://github.com/organizations/BTCDecoded/settings/profile as an organization owner.
2. Under Profile picture, click Upload new picture and choose `btcdecoded_org_avatar_512.png` from this folder.
3. Click Set new profile picture, then check https://github.com/BTCDecoded and an auto social card (for example a repository link preview).
